# 生成数据驾驶舱原型

数据大屏相关任务始终先由本 Skill 判断入口。新方案先确认文字方案，再生成候选图；用户提供完整目标大屏截图并要求直接还原时，跳过方案和候选图，将截图直接冻结为选中图片。选图后严格按截图还原流程完成 HTML 主规格，再进行 React 工程化和同视口验收。

## 强制阶段门禁

### 1. 判断入口并临时对齐

- 用户提供完整目标大屏截图并明确要求还原时，跳过本阶段和候选图生成，直接进入“冻结选中图片”。仅把图片当作风格参考或内容参考时，仍生成新方案。
- 其他情况只对齐会影响候选图的业务内容；需要行业提示时读取 [industry-scenes.md](references/industry-scenes.md)，并按 [style-alignment.md](references/style-alignment.md) 对齐板块、布局、中央载体、风格和主题色。
- 本 Skill 是 client 默认设计对齐流程的明确例外：跳过 `DESIGN.md` 候选、主题深链和设计基底确认，不新建 `DESIGN.md`，也不复用其中的 tokens。
- 需求对齐只用于生成图片提示词。图片冻结前不创建或更新主规格，也不创建需求 Brief、PRD、素材清单等中间文档。

### 2. 对比并确认文字方案

按 [style-alignment.md](references/style-alignment.md) 先展示文字方案；用户未指定数量时默认 3 套。每套都要明确板块与布局、中央载体、风格、主题色、推荐理由和主要取舍，差异不能只是换色。

展示后停止并等待用户明确确认一个或多个方向，或要求合并、修改后再确认。用户明确指定单一参考图、风格方向或只要一套时，先用一套文字方案复述最终方向；仅提供零散约束且未指定方向或数量时仍默认 3 套。确认前不得调用 `ui-image-generation`、图片接口或展开完整提示词。

### 3. 生成候选图片

读取并遵循 `../ui-image-generation/SKILL.md`；同时使用 `../explore-options/SKILL.md` 让候选方案在构图、主 VI 或信息组织上有实质差异。

- 只为用户确认的方向生成图片；用户没有额外指定数量时，每个确认方向默认生成 1 张。
- 展示全部候选图，说明核心差异，等待用户选择。
- 用户要合并多个方案时，先生成一张合并后的新图，再等待明确选择。
- 用户只要候选效果图时，完成本阶段后停止，不进入原型还原。

### 4. 冻结选中图片

只有用户明确选中图片后才能进入还原阶段：

1. 将最终图片复制到目标原型的 `.spec/reference/selected-source.png`，记录尺寸和 SHA-256。
2. 选中图片是所有可见视觉事实的唯一还原标准；不使用前期需求纠正选中图片。
3. 选图后才整理图片无法表达且仍有效的非视觉运行约束，例如数据源/时效、地图服务、真实 3D、交互、动画、性能和权限；冲突或不确定项先请用户确认，再交给规格子代理写入主规格，不另建 Brief。
4. 用户最新明确修改优先于图片，并同步到后续规格；明显视觉改向时重新冻结参考图。

### 5. 由规格子代理实际实现主规格

按 [subagent-handoffs.md](references/subagent-handoffs.md) 启动干净的规格子代理，以选中图片为源图严格执行 `screenshot-to-prototype`，并按 [visual-routing.md](references/visual-routing.md) 提取常用视觉元素、处理素材以及确定图表、地图、3D 和动画路线。

这一阶段必须实际实现同 viewport 的 HTML 主规格 `.spec/spec.html`，包括可见布局、框架、素材、真实文本、数据内容和关键状态；不得只写说明、留下可实现的占位内容，或把真实图表和交互控件切成位图。选定的正式技术路线必须在主规格中可见运行，不得留到 React；视觉元素实现清单、逐元素验证和技术路线随主规格一并确认。

规格完成后，提供完整 Make 服务规格评审链接并结束当前回合，等待用户评审；不要继续写 React。

### 6. 由实现子代理制作 React 原型

用户明确确认当前 HTML 主规格后，才按 [subagent-handoffs.md](references/subagent-handoffs.md) 使用与规格子代理不同的干净子代理，将已确认主规格工程化为 React 原型。

- 复用主规格已确认的结构、素材、组件拆分和技术路线，不重新选择视觉风格、素材方案或技术路线。
- 接入真实数据、状态管理、交互和生产运行能力；规格不清楚或需要可见降级时，回到规格阶段等待用户确认。
- 完成后同步主规格中的实现状态与必要偏差，不回填早期对齐内容。

### 7. 由验收子代理独立检查

按 [subagent-handoffs.md](references/subagent-handoffs.md) 使用第三个干净的验收子代理，在相同 viewport 下对比选中图片、HTML 主规格渲染和 React 运行页；问题回交相应阶段修复。

# 行业场景提示

本文件只用于需求对齐和提示词设计；图片确认前不落盘，也不要求逐项询问或记录。仅选择会改变候选图的关键问题。

## 对齐维度

| 字段 | 用途 |
| --- | --- |
| 目标角色 | 决策层、调度员、运维人员、值班人员或公众展示 |
| 核心任务 | 态势总览、监控预警、指挥调度、分析研判或成果展示 |
| 常见主题 | 行业对象、事件、空间范围和时间范围 |
| 推荐主 VI | 地图、园区、工厂、设备、数字孪生体、关系网络或关键指标 |
| 常见指标 | 规模、效率、质量、能耗、安全、告警、趋势和排名 |
| 数据来源 | IoT、SCADA、BIM/GIS、业务系统、视频、日志或第三方平台 |
| 数据时效 | 实时、分钟级、小时级、日统计或历史回放 |
| 告警体系 | 告警等级、状态、位置、处置进度和责任人 |
| 地图需求 | 无地图、行政区态势、园区空间或真实底图定位 |
| 3D 适用度 | 装饰性、空间关系必要、设备操作必要或无需 3D |
| 常见交互 | 筛选、联动、钻取、轮播、时间轴、漫游、点选和回放 |
| 素材需求 | 品牌、背景、模型、地图、纹理、图标、边框和媒体资源 |
| 风险项 | 数据可得性、地图授权、模型精度、性能、涉密和大屏可读性 |

## 提问原则

优先确认屏幕比例/分辨率、目标角色、核心任务、行业对象、必须出现的内容、地图类型、3D 是否承担真实空间表达，以及候选图片数量。视觉方向不明确时提供少量互斥选项；用户已经给出答案时不要重复询问。

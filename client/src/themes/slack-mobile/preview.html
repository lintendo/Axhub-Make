使用建议

建议

  • 建议：Use Slack Aubergine ({#4A154B}) as the default sidebar color — it's the signature brand anchor。
  • 建议：Make sidebar color workspace-customizable (admin setting) — allow any hex。
  • 建议：Use rounded-square (4pt corner) avatars — NOT circles — Slack's distinct choice。
  • 建议：Surface reactions below every message as inline pill chips with emoji + count。
  • 建议：Show threads as first-class: "5 replies, last reply 3h ago" link + slide-in pane on tap。

避免

  • 避免：use circle avatars — rounded-square (4pt) is Slack's signature。
  • 避免：hardcode the sidebar color — it's workspace-customizable。
  • 避免：use Slack aubergine anywhere except the sidebar (and login screens) — it's the sidebar's color。
  • 避免：put mentions without the colored pill background — the pill IS the mention。
  • 避免：ignore threads — they need a sliding pane, not a tap-through replacement of the main view。

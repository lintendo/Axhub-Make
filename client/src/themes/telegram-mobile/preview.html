使用建议

建议

  • 建议：Use {#0088CC} (Telegram Blue) as the default accent — but build the system so accent is a single variable that users can change。
  • 建议：Use {#2B86FD} for outgoing bubbles in default blue theme; support accent-tinted outgoing bubbles。
  • 建议：Respect user-selected chat backgrounds (solid, gradient, tile, photo)。
  • 建议：Use SF Pro + Telegram's proprietary outlined icon vocabulary (NOT web-accessible icon alone)。
  • 建议：Offer OLED dark mode ({#000000}) as a distinct option from default dark。

避免

  • 避免：hardcode accent color — theme it; the accent variable should cascade。
  • 避免：use WhatsApp's asymmetric tail — Telegram bubble tails are SUBTLY notched (6pt), not pointed。
  • 避免：use warm cream chat backgrounds; Telegram defaults to cool white/soft-blue or pure dark。
  • 避免：use web-accessible icon for everything — Telegram's tab bar uses outlined custom glyphs。
  • 避免：dim the whole screen on long-press — only the backdrop around the context menu blurs。

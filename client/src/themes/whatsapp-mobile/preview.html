使用建议

建议

  • 建议：Use {#25D366} (WhatsApp Green) for send, answer-call, record, and positive primary actions。
  • 建议：Use {#D9FDD3} (light) or {#005C4B} (dark) for outgoing bubbles — the mint-leaf is iconic。
  • 建议：Keep bubble tails asymmetric — rounded all corners except one pointed at sender。
  • 建议：Rely on Dynamic Type; never hardcode pt sizes that won't scale。
  • 建议：Use SF Pro + web-accessible icon as your default — WhatsApp looks native because it IS native。

避免

  • 避免：use pure black canvas — WhatsApp dark mode is {#111B21}, a blue-black。
  • 避免：round bubble corners equally — the asymmetric tail is core to the form language。
  • 避免：use red for send or positive actions — red is reserved for delete, fail, and call-decline。
  • 避免：place the "new chat" FAB inside the tab bar — keep it as a nav-bar trailing icon。
  • 避免：add custom fonts — WhatsApp's iOS typography is pure SF Pro。

使用建议

建议

  • 建议：Use {#00C805} (Robinhood Green) for all upward portfolio movement, buy CTAs, profitable positions。
  • 建议：Use {#FF5000} (Robinhood Red — orange) for downward movement and loss states — note this is orange, NOT red。
  • 建议：Use a true red {#E62232} only for hard error states (order failed, system error) — keep it distinct from the loss orange。
  • 建议：Render every $-amount and every percentage in Capsule Sans Text with tabular numerals。
  • 建议：Use Capsule Sans Display (40pt+ Bold) for the hero portfolio value at the top of the Investing tab。

避免

  • 避免：use green for a down number or orange for an up number — color is bound to direction。
  • 避免：use legacy red {#FF0000} for losses — Robinhood Red is specifically orange ({#FF5000})。
  • 避免：add gradients to the chart line area — modern Robinhood is just the line, no fill。
  • 避免：render numbers in proportional figures — always tabular numerals。
  • 避免：crowd position rows below 56pt — the data density is already at its limit。

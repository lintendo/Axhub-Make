使用建议

建议

  • 建议：Use Jira Blue ({#0052CC}) ONLY for primary actions, links, and selected states — never as a content background。
  • 建议：Keep the canvas and chrome neutral gray so semantic colors carry meaning。
  • 建议：Render status as a lozenge — uppercase, tracked, semantic-colored, 3pt radius。
  • 建议：Use the correct issue-type icon + color (green Story / red Bug / blue Task / purple Epic / gray Sub-task)。
  • 建议：Pair every card footer with issue-type icon + key on the left, points + assignee on the right。

避免

  • 避免：use Jira Blue as a card or section background — it must read as "action only"。
  • 避免：introduce new accent colors — the semantic set (blue/green/red/yellow/purple/neutral) is the whole palette。
  • 避免：show status as plain text — always a colored lozenge。
  • 避免：let issue cards grow unbounded — 2-line summary clamp is mandatory。
  • 避免：use pure black text ({#000000}) — {#172B4D} navy ink is correct on light。

使用建议

建议

  • 建议：Use Coinbase Blue {#0052FF} for primary CTAs, active tab, and the C-mark — it's the core brand action color。
  • 建议：Use Coinbase Display for hero portfolio values (40pt+); use Coinbase Sans for everything else。
  • 建议：Use Coinbase Mono ONLY for wallet addresses, transaction hashes, and order book numbers。
  • 建议：Render each crypto asset's icon with its official brand color (Bitcoin orange, ETH purple, USDC blue) in a 40pt circle with the asset's glyph in white centered。
  • 建议：Use tabular numerals on every price, percentage, and quantity — the institutional asset list look depends on it。

避免

  • 避免：use any other blue as the brand accent — Coinbase Blue {#0052FF} is the only correct shade。
  • 避免：use pure black {#000000} for text — {#0A0B0D} (slight cool tint) is correct。
  • 避免：use Coinbase Sans for wallet addresses — Mono is required for technical readouts。
  • 避免：replace the asset's brand color icon with a monochrome version — the orange / purple / blue diversity is part of the visual identity。
  • 避免：crowd asset rows below 60pt — the rich icon + 2-line text + sparkline + price + change needs room。

首页工作台（home-pilot）已实现

原型 id：home-pilot 原型目录：src/prototypes/home-pilot/ 来源：Axure 导入原型 src/prototypes/html/ page-002 更新：2026-07-31（将 meeting-pilot 会议列表与归档详情、info-pilot 信息列表与详情合并至 home-pilot；顶部导航「会议」「信息」改为进入 home-pilot 内部页面；删除 meeting-pilot 与 info-pilot 原目录）

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

原型意图：将 Axure 导入原型中的「首页（非领导）」页面，以 Axhub Make 原生 React 重新实现，作为系统的非领导用户工作台入口，统一使用 sinopec-workbench 主题组件与视觉规范。

使用场景：集团董事会 / 董办非领导人员登录后查看待办事项、快速发起各类业务申请、进入常用系统。

当前表达：十四个 Hash 页面——home（首页工作台）、regulation（制度列表）、regulation-create（制度发起）、meeting-create（会议发起表单）、meeting-todo（会议发起待办审批）、meeting-archive（会议材料归档发起）、meeting-list（会议列表）、meeting-detail（会议材料归档详情）、research-list（调研列表）、research-detail（调研详情）、research-create（调研发起）、info-list（信息列表）、info-detail（信息详情）、info-create（董事参考信息发起）；默认页为 home。会议发起、待办审批、材料归档发起、调研发起与信息发起以内嵌页面形式置于首页原型中，入口均从首页进入；制度列表通过顶部导航「制度」进入，会议列表通过顶部导航「会议」进入，信息列表通过顶部导航「信息」进入。会议发起表单按「通知类型」切换字段，三种类型分别为会议安排、议案材料、会议记录。

事实与输入

用户确认事实

  • 本轮范围：Axure 页面 page-002 首页（非领导），共 1 个页面。
  • 入口页不转换：用户明确「入口页面不用转换」，因此 home-pilot 不包含 page-001 入口。
  • 保真度：按生产级界面重写，保持原页面的信息架构、模块与核心交互，不追求像素级复刻。
  • 放置位置：独立原型目录 src/prototypes/home-pilot/，保留 html/ 原型不动。
  • 设计基底：采用 src/themes/sinopec-workbench/DESIGN.md。
  • 组件来源：顶部导航、分页器及通用基础样式从 src/themes/sinopec-workbench/components 与 styles 导入。
  • 交互完整度：mock 数据驱动（分类 tab 筛选 / 分页可用）。
  • 顶部导航：采用通用导航组件 AppTopNav，7 个一级菜单中当前模块高亮；「首页」「制度」「会议」「信息」「调研」「我的发起」可点击并跳转；「我的发起」中展示董事签字任务；「议案」暂未接入，禁用置灰。
  • 会议与信息页面合并：将 meeting-pilot 的会议列表与会议材料归档详情、info-pilot 的信息列表与信息详情合并至 home-pilot，作为 meeting-list、meeting-detail、info-list、info-detail 四个 Hash 页面；合并后删除 src/prototypes/meeting-pilot/ 与 src/prototypes/info-pilot/ 目录。
  • 会议相关页面内嵌：用户明确待办审批和发起会议的入口都在首页，倾向「首页内嵌页面」的实现方式；因此将会议发起表单、会议发起待办审批与会议材料归档发起作为 home-pilot 的内嵌页面，入口分别从首页的「会议发起」磁贴、「会议」分类待办标题与「材料归档」磁贴进入。
  • 董事签字接入：首页发起申请磁贴中材料归档后增加「签字发起」入口，点击跳转至 src/prototypes/director-sign/#page=create；董事会事务待办中增加「董事签字」业务类型，点击标题跳转至对应审批页；「我的发起」列表中第一页展示董事签字任务，支持查看与已驳回状态的修改跳转。
  • 主规格格式：HTML，固定路径 .spec/spec.html。

设计基底与原型特有调整

采用的 DESIGN.md

src/themes/sinopec-workbench/DESIGN.md —— 中国石化集团董事会工作台设计系统。

继承方式

  • 颜色、字体、圆角、阴影、间距全部走主题 CSS 变量 --swb-*。
  • 通用组件（TopNav、Pagination）从主题导入。
  • 卡片：白底、6px 圆角、极浅阴影、24px 内边距。
  • 磁贴：72px 高、8px 圆角、浅色渐变背景、左侧图标、hover 阴影 + 微缩放。
  • 表格：表头 #fafafa、52px 行高、行间无分割线、hover 浅蓝背景。
  • 分类 tab：按钮组样式，选中项蓝底白字。

本原型特有调整

  • 发起申请磁贴从原型的 6 个图标文字块简化为统一磁贴组件；「制度发起」采用品牌蓝底白字的强调态，其余磁贴保留浅色渐变。
  • 常用系统磁贴使用蓝/绿/琥珀渐变，与发起申请磁贴风格一致。
  • 待办事项区分左侧一级页签（待办 / 已办）与右侧二级页签（公文 / 董事会事务 / 会议，无「全部」）；待办与已办下均展示这三个业务页签；默认进入「待办-公文」。
  • 会议发起表单、会议发起待办审批、会议材料归档发起、调研发起与信息发起以内嵌页面形式接入 home-pilot，与首页共用同一份入口、主题和样式文件；相关表单/详情样式由 home-pilot/style.css 统一维护。
  • 会议列表与会议材料归档详情、信息列表与信息详情从 meeting-pilot 与 info-pilot 迁移合并至 home-pilot，作为 meeting-list、meeting-detail、info-list、info-detail 四个 Hash 页面，样式与 mock 数据统一收归 home-pilot 维护。
  • 调研发起页、董事参考信息发起页与会议发起页均采用左右两栏布局：左侧为带标签的表单，右侧为「填写意见」与「提交流程」操作边栏，部室负责人与提醒方式使用复选框。
  • 董事参考信息发起页的左侧表单字段包括名称、类别（月报 / 季报 / 专报 / 专项报告 / 工作安排 / 其他）、密级（无 / 普通商密 / 内部）、日期、情况简述（200 字限制）与附件上传。
  • 会议发起页左侧表单以「通知类型」单选切换三种业务场景：会议安排（文件名称 + 附件）、议案材料（文件名称 + 密级 + 会议类型多选 + 会议日期 + 情况简述 + 附件）、会议记录（文件名称 + 密级 + 情况简述 + 附件）；情况简述限制 500 字。
  • 会议列表顶部增加分类标签（全部 / 董事会 / 各专业委员会），与搜索区组合过滤。
  • 信息列表采用 Chip Tab 做类型筛选，表格增至 7 列并支持名称/类型/时间列排序；详情页改为顶部横向 tab，流程跟踪拆分为 6 组记录表。

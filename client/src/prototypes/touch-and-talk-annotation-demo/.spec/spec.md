# Touch And Talk 批注演示规格

> 本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

## 当前方案

- 原型意图：用带章节目录的教程式演示介绍 Touch And Talk 批注协作，通过文案、图标和截图说明点选元素、输入或口述意图、常用编辑技巧、快速执行路线和扩展场景。
- 使用场景：原型评审者、设计参与者和实现参与者按七章顺序建立概念、理解批注流程和能力边界；页面不区分登录身份、角色或权限。
- 当前表达：每次只渲染一个章节，左侧目录和页脚按钮通过 Hash 在线性章节间切换；教程内容与当前组件实际可执行能力分开记录。

## 原型范围

### 本次呈现

- 七个章节的页面键、顺序、目录标签、标题、眉题、摘要和 tone。
- 封面三条原则、快速批注四步、语音示例与建议、四个常用技巧、批注能力条件、两条执行路线和三个扩展场景。
- 四张截图的文件、标题、替代文本、说明和当前组件位置。
- 章节 Hash、当前态、前后页禁用边界、未知页面回退和嵌入宿主路由消息。
- 当前局部样式的结构、响应式断点、键盘焦点和语义属性。

### 本次不呈现

- 麦克风权限、录音、语音识别、纠错或语音模型选择。
- 截图内部控件、元素选择、批注输入、剪贴板复制、提示词执行、AI 修改或技能执行。
- 双击编辑、样式编辑、图片粘贴、恢复交互、文档批注、移动端批注或双端批注的真实产品交互；这些只作为教程陈述。
- Make 批注回写、评审运行时集成、用户数据、后端请求、进度状态、身份权限、分析埋点或完成测验。
- 主规格自身的搜索、分页、Hash 导航或验收勾选持久化；这些旧 HTML 文档交互不属于原型方案。

## 交互与状态方案

| 对象/场景 | 前置状态 | 用户操作 | 原型表现 | 后续状态 |
| --- | --- | --- | --- | --- |
| 页面路由 | 无路由或合法 `#page=<pageId>` / `?page=<pageId>` | 打开原型或改变 Hash | 初始化先读 Hash，再读查询参数，最后回退 `cover`；页面 id 仅允许小写字母、数字和连字符 | 当前章节、tone、页码、标题、内容及相邻页同步更新；格式合法但未注册的 id 在组件层显示封面 |
| 侧栏章节按钮 | 当前章节已确定 | 点击任一章节 | 调用 `setPage(chapter.id)` 写入 Hash；当前按钮增加 `is-active` 和 `aria-current="page"` | 可跳过前序章节直接访问目标章 |
| 上一页 / 下一页 | 当前章节已确定 | 点击页脚按钮 | 按章节数组索引线性切换；封面禁用上一页，末章禁用下一页 | 不循环；没有完成提示或跳转动作 |
| 截图媒体 | 进入封面、快速流程或快速执行章节 | 浏览截图 | 以 `object-fit: contain` 完整显示，提供标题、替代文本和说明 | 图片内部没有热点或可点击 DOM |
| 点选与批注教程 | 浏览快速流程、技巧或截图 | 阅读教学内容 | 展示流程卡、技巧卡和截图 | 不启用标注运行时或元素选择处理器 |
| 语音输入教程 | 浏览语音批注章节 | 阅读摘要、口述建议和静态转写 | 展示文字与图标 | 不请求麦克风、不录音、不调用识别 API |
| 复制提示词教程 | 浏览快速流程第 4 步 | 阅读“复制提示词”说明 | 展示静态步骤卡 | 不调用剪贴板，不显示复制反馈 |
| 批注能力条件 | 浏览能力条件章节 | 阅读各项功能对应的使用条件 | 展示“执行 Agent、批注技能”两项额外条件矩阵；窄屏下可横向滚动 | 不触发批注、编辑、AI 执行或需求标注操作 |
| 页面直接执行教程 | 浏览 Route A | 阅读文字和截图 | 说明 AI 可在页面现场处理修改意图 | 不构造提示词、不发起网络请求、不运行 AI |
| 技能读取批注教程 | 浏览 Route B | 阅读文字和截图 | 说明 AI 可通过技能读取批注 | 不加载技能、不读取批注、不启动处理任务 |
| 嵌入宿主通知 | 当前窗口嵌入父窗口 | 路由注册或 Hash 变化 | 发送 `AXHUB_PROTOTYPE_ROUTE_INFO` 或 `AXHUB_PROTOTYPE_PAGE_CHANGE`，只包含路由信息 | 独立窗口不发送；消息不包含批注内容或写回 |

## 设计基底与原型特有调整

- 采用的 `DESIGN.md`：无；当前原型未引用独立 `DESIGN.md`，仅以 `style.css` 中可观察的 E-Ink Magazine 式纸张版面为事实基底。
- 继承方式：不适用；当前实现使用深墨蓝 `#0a1f3d`、浅纸色 `#f1f3f5`、纸色变化 `#e4e8ec`，以及 serif、sans、mono 三类字体栈。
- 本原型特有调整：桌面为 280px sticky 侧栏加最大 1120px 舞台，深浅章节共享细网格、边线和纸张式结构；在 1100px 和 760px 断点依次收窄侧栏、改为单列和横向滚动导航；当前章节使用 `aria-current`，图片提供替代文本，装饰元素对辅助技术隐藏，按钮提供 `:focus-visible` 轮廓。

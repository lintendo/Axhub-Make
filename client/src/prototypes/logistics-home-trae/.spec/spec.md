# 联途物流官网首页 - TRAE 主题主规格

> 本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并记录会影响当前原型的重要用户决策和变更。

## 当前方案

- 原型意图：创建一个接近正式产品的国内综合物流官网首页，以清晰的运输服务能力和可信数据承接新客户询价，同时为存量客户提供运单查询。
- 使用场景：企业供应链负责人、运营人员和中小企业主首次了解服务，或已有客户查询运输进度。
- 当前表达：使用 TRAE `DESIGN.md` 的暗色工程化界面、荧光绿单一强调、真实状态画面和直角组件，把物流服务表达为稳定、可视、可协同的数字化履约平台。
- 当前状态：原型已实现；新增文件限定 TypeScript 检查、桌面/移动端布局、图片加载、查单、询价和移动菜单验收通过。

## 事实与输入

### 用户确认事实

- 本原型使用与 Uber、T1 Energy、Mintlify 三版完全相同的品牌、文案、示例数据、模块、功能和核心交互。
- 业务定位为国内综合物流，覆盖企业零担、整车、仓配和供应链服务。
- 首页首要转化目标为“查单 + 询价”。
- 本原型只采用 TRAE 设计规范，不混入另外三套主题的 token 或组件语言。
- 主规格沿用 Markdown。

### 参考资料

- `src/themes/trae/DESIGN.md`：本原型唯一视觉基底。
- `src/prototypes/logistics-home-core.tsx`：四版共用内容、数据和交互事实源。
- 三版既有物流图片：继续复用同一组车辆、仓储与调度场景资产，保证内容对比一致。

### 当前假设

- 继续使用虚构品牌“联途物流 LINKROUTE”，不影射真实企业。
- 所有经营指标、客户案例、运单与报价结果均为演示数据。
- 原型不接入后端、地图、真实运单或真实计价服务。
- TRAE 原始主题偏开发者工具，本版只迁移其视觉语言，不把物流内容改写为 IDE 或 AI 产品。

## 原型范围

### 本次呈现

- 响应式单页官网首页，覆盖桌面 `1440x900` 与移动端 `393x852`。
- 顶部导航、首屏品牌与服务价值、查单/询价双入口、可信数据、核心服务、网络能力、行业方案、履约流程、客户证言、行动区与页脚。
- 查询、询价、移动端菜单、锚点导航和必要的表单反馈。

### 本次不呈现

- 登录注册、用户中心、完整服务详情页、新闻详情页、在线支付、客服系统。
- 真实地图、实时轨迹、价格算法、验证码、接口请求和数据持久化。
- 页面内主题切换；本版保持独立预览地址。

## 交互与状态方案

| 对象/场景 | 前置状态 | 用户操作 | 原型表现 | 后续状态 |
| --- | --- | --- | --- | --- |
| 查运单 | 默认激活，输入为空 | 输入任意非空运单号并提交 | 按钮显示短暂加载，随后在工具区展开演示轨迹；空值提交显示字段错误 | 结果可关闭，输入值保留 |
| 获取报价 | 切换到询价页签 | 填写必填项并提交 | 缺项就地校验；完整提交后显示成功反馈与需求摘要 | 可返回修改，不发出真实请求 |
| 顶部导航 | 页面任意位置 | 点击服务、网络、行业方案、关于我们 | 平滑滚动到对应区块并保持清晰焦点 | URL 不跳转 |
| 移动端菜单 | 宽度小于导航容纳范围 | 点击菜单图标 | 展开全宽导航层；选择项目后关闭并滚动 | 页面正文位置保留 |
| 服务与方案项 | 默认静态 | 悬停、聚焦或轻触 | 使用 TRAE 规范的细边界、暗色叠层和荧光绿焦点反馈 | 不进入详情页 |

## 设计基底与原型特有调整

- 采用的 `DESIGN.md`：`src/themes/trae/DESIGN.md`
- 继承方式：严格使用 `#0A0B0D` 页面底、`#121314` 表面、`#32F08C` 单一品牌强调、0-4px 圆角和 Inter / JetBrains Mono 字体角色。
- 首屏目标：物流实景作为全幅背景，标题与双入口保持第一视口可见；不使用大面积渐变、光球或玻璃拟态。
- 信息层级：短标题、状态标签、真实调度画面和严格能力网格优先，弱化装饰性营销表达。
- 布局骨架：桌面使用宽容器、工程索引、2-3 列能力网格与暗色状态台；移动端单列化，核心操作不隐藏。
- 交互路径：查询默认激活，询价同级切换；所有输入、焦点、错误和成功状态使用明确边界与语义色。
- 数据呈现：规模数据和路线节点采用等宽短标签与状态条，避免伪造复杂实时控制台。
- 原型特有调整：荧光绿只用于主操作、索引、焦点和运输中状态；图片仍展示真实物流作业，不替换成软件界面截图。

## 验收重点

- 与前三版固定文案、数据、模块和交互逐项一致。
- `1440x900` 与 `393x852` 下无横向溢出、文本截断、控件跳动或元素重叠。
- 首屏同时看见品牌、物流实景和双入口，下一段内容在第一视口底部露出。
- 查单和询价具备空值、加载、成功反馈；导航和移动菜单可用。
- 视觉上能明确识别为 TRAE 的暗色工程化设计语言，同时保持物流行业可信度。

# 企业级数据可视化大屏：8 组视觉风格提示词参考

本资料整理了 8 组可复用的企业级数据可视化大屏视觉提示词，并为每组提示词配套一张原生 3840×2160 参考图。提示词重点描述视觉风格、画面构图、信息架构、中央载体、模块形式和渲染方式；实际使用时可以替换行业、标题、业务对象和指标，但不要为了制造差异而删减设计描述或业务模块。

## 使用方法

使用前先替换以下变量：

- `[行业名称]`：如新能源、工业制造、供应链、农业、水利、医疗、零售、金融、交通或城市治理。
- `[大屏标题]`：如“新能源运营中心”“智慧工厂指挥中心”“全球供应链控制塔”。
- `[中央载体]`：如能源基地、工业园区、仓储网络、区域 GIS 地图、设备拓扑或抽象数据沙盘。
- `[核心业务对象]`：如场站、产线、仓库、门店、医院、农田、河网、车辆或城市设施。
- `[关键指标]`：根据行业替换发电量、订单量、产能、库存、客流、设备效率、告警数等指标。

统一生成约束：

1. 画布使用 16:9 横向桌面大屏，正式素材建议使用原生 3840×2160；快速试稿可使用 1920×1088 或 2048×1152。
2. 输出一张完整的数据驾驶舱界面，不要生成浏览器边框、显示器模型、手机界面或外部展示场景。
3. 界面主体使用中文；行业缩写和单位可以保留，例如 OEE、SOC、MW、MWh、%、tCO₂。
4. 标题、大数字、模块标题和核心状态必须清楚，避免大量无意义微型文字、英文占位符和明显乱码。
5. 参考图只用于确认视觉方向和信息密度，不要求复刻其中的具体数据。
6. 原型按正式产品级界面描述，不使用 wireframe、placeholder、draft 等低保真表达。

## 01. 电影科幻 FUI 风格

![电影科幻 FUI 风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F01-cinematic-fui-4k.webp?projectId=make-project)

适合需要表现高实时性、高信息密度、精密控制和未来操作台氛围的行业。行业内容可以替换，但应保留深色空间、HUD 细节、中央数字孪生、多层数据覆盖和高密度驾驶舱结构。

### 完整提示词

```text
企业级[行业名称]数字孪生 FUI 数据可视化大屏设计，标题为“[大屏标题]”。整体采用电影级科幻 UI 视觉与极简工业设计语言，界面是一张可实际使用的正式运营驾驶舱，不是概念海报或低保真线框图。

配色与氛围：使用深色未来数字空间背景，包含细密科技网格、精确刻度、HUD 光效、扫描线、微型图标和轻微体积雾。主色采用低饱和度深海蓝、墨蓝、科技青和冰蓝，少量使用森林绿、沙滩金或橙黄色标记正常、关注和告警状态。整体呈现高级、克制、专业的硬核科技感，避免廉价霓虹和过度赛博朋克。

顶部区域：顶部设置具有机械切角和精密线框的标题栏，显示“[大屏标题]”、日期时间、区域筛选和系统状态。标题下方设置 5–6 个紧凑 KPI，展示[关键指标]，包含主数值、单位、同比环比、趋势箭头和状态标识。

中央核心（数字孪生）：画面中央为悬浮式高精度三维[中央载体]数字孪生沙盘。模型基于真实地形、建筑、设备和业务设施构建，具备清晰的空间层级、PBR 材质、轮廓辉光和环境遮蔽。沙盘上分布动态数据节点、发光 Marker、设备标签、数据连线、热力区域、扫描圈环和粒子流，用于表现[核心业务对象]的实时运行状态。中央模型占画面约 40%–50%，保持第一视觉中心，但不能遮挡外围数据。

左右 UI 布局：左右两侧采用对称或近似对称的模块化数据驾驶舱窗口，面板使用多层信息叠加、半透明深色底、精密切角、细线边框、刻度和扫描效果。每侧至少包含 3 个完整模块，避免只留下孤立的小卡片。

左侧模块：聚焦基础设施与实时监控。包含系统计算状态、设备运行参数、实时趋势双折线图、设备健康度、GIS 或拓扑状态、资源负载和场站排行。使用大数字、迷你趋势、环形仪表和横向进度条建立清晰层级。

右侧模块：聚焦业务分析与运营结果。包含业务完成量柱状图、结构占比环形图、雷达分析图、告警事件列表、用户或对象画像、计划达成率和异常处置状态。告警使用红橙色，但不破坏整体冷色基调。

底部区域：增加横向运行态势、业务流向或节点明细表，展示时间、对象名称、实时数值、健康状态、通讯状态和处理进度。底部模块应完整可读，不与中央模型重叠。

渲染与细节：3D 写实渲染，HDRI 环境光，强而克制的 Bloom 辉光，AO 环境遮蔽，Global Illumination，Ray Tracing，超高质量 PBR 材质，电影级景深和体积光。画面为 16:9 横向 4K 大屏，原生 3840×2160，中文界面，一张完整屏幕，无浏览器边框、无设备外框、无水印。

避免：大面积空白、低信息量、只有中央模型没有业务面板、普通蓝色后台模板、白色 SaaS、过度炫光、文字噪点、英文标题和明显乱码。
```

## 02. 全息晶格科技风格

![全息晶格科技风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F02-holographic-lattice-4k.webp?projectId=make-project)

适合突出网络关系、空间拓扑、节点连接和全息投影效果。与电影科幻 FUI 的区别是：中央透明晶格模型和投影底座必须成为核心，外围面板保持悬浮和轻量，不使用厚重的普通矩形卡片。

### 完整提示词

```text
未来科技风[行业名称]数字孪生综合运营大屏，标题为“[大屏标题]”。画面展示悬浮于纯黑科技空间中的三维[中央载体]全息模型，整体是一张正式可用的企业级数据驾驶舱。

配色与氛围：深黑与墨蓝背景，电蓝、冰蓝和青色作为主要发光色，少量橙黄色用于业务流向和告警重点。背景具有科技网格、点阵、扫描线和纵向数据光柱，但保留足够暗部，让全息模型轮廓清晰。整体冷静、硬核、精密，不使用大面积紫色赛博朋克霓虹。

中央核心（全息晶格模型）：中央悬浮高精度三维[中央载体]，采用透明玻璃晶格、线框切片、分层结构和明亮电蓝描边。模型内部呈现[核心业务对象]、连接线路、能源或数据流、节点状态、扫描环和动态粒子。模型底部设置大型环形光能支撑平台与全息投影光束，形成从底座向上托起模型的空间关系。中央模型占画面约 45%–50%，始终是第一视觉中心。

顶部区域：顶部采用窄长科技标题栏，显示“[大屏标题]”、日期时间、环境状态和区域筛选。标题下方布置 5 个紧凑 KPI，显示[关键指标]，每个 KPI 包含大数值、单位、同比环比和趋势箭头。

左侧模块：使用三组纵向悬浮 HUD 模块，分别表现实时趋势、对象排行和核心设备状态。趋势图采用双折线和微型坐标网格；排行采用横向能量条；设备状态采用环形仪表、充放电或输入输出数值。

右侧模块：使用三组纵向悬浮 HUD 模块，分别表现业务构成、电网或网络负荷、告警事件。构成模块使用发光环形图；负荷模块使用柱状图叠加峰谷曲线；告警模块展示时间、对象、等级和状态，使用红橙蓝小型状态标签。

底部区域：底部左侧展示业务流向拓扑，以发光箭头连接多个关键节点；底部右侧展示 5–6 行节点运行明细，包含名称、类型、容量、实时数值、健康状态和通讯状态。底部面板采用低矮横向结构，不遮挡投影底座。

UI 语言：所有面板使用深色半透明浮层、精密切角、细线发光边框、扫描标记和微型图标，不使用厚重大卡片。信息丰富但层级清楚，主要标题和大数字清晰可读。

渲染与细节：Octane Render、Blender 或 C4D 真实 3D 渲染，高精度模型、透明玻璃材质、自发光线框、体积光、Bloom、AO、Global Illumination 和电影级全息投影效果。16:9 横向 4K 大屏，原生 3840×2160，中文界面，无浏览器边框、无设备外框、无水印。

避免：只有四个节点卡片、外围信息过少、普通企业蓝 IOC、白色 SaaS、写实自然景观、中央模型被面板遮挡、英文标题和明显乱码。
```

## 03. 企业科技蓝 IOC 风格

![企业科技蓝 IOC 风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F03-enterprise-blue-ioc-4k.webp?projectId=make-project)

适合城市、交通、园区和企业运营等通用 IOC 场景。重点是标准、稳定、清晰的模块化信息架构，不追求过度电影化或夸张全息效果。

### 完整提示词

```text
企业级[行业名称] IOC 综合运营驾驶舱，标题为“[大屏标题]”。整体采用成熟的企业科技蓝数据可视化设计语言，强调清晰、稳定、专业和高可读性，呈现一张可以用于运营监控与指挥决策的正式大屏界面。

配色与氛围：背景使用深海军蓝到墨蓝的渐变，叠加低对比度城市网格、数字纹理和细微光点。主色为科技蓝、冰蓝和青色，绿色表示正常，橙色表示关注，红色表示异常。卡片边框和标题装饰保持克制，避免强烈赛博朋克和过度 Bloom。

整体布局：采用经典 IOC 构图。顶部为标题、导航、时间、区域筛选和系统状态；标题下方布置 5–6 个核心 KPI；中部为“左侧业务面板 + 中央 GIS 或数字沙盘 + 右侧业务面板”；底部为指标卡、事件列表或运行明细。界面信息饱满、网格对齐、模块尺寸统一。

中央核心：中央展示[中央载体]的二维 GIS 地图、2.5D 区域地图或轻量三维沙盘。地图包含行政区、道路、设施、业务点位、热力区域、轨迹线、告警 Marker 和状态标签。中央区域约占画面 35%–45%，用于承载空间态势，而不是纯装饰背景。

左侧模块：聚焦资源总览和实时监测，包含[关键指标]、趋势折线图、资源构成环形图、对象排行、设备在线率和区域状态。至少包含 3 个完整模块，每个模块有清晰标题、图例、单位和数据层级。

右侧模块：聚焦运营分析和事件处置，包含业务完成量柱状图、计划达成率、告警分类、事件列表、处置进度、用户或对象画像。使用状态标签和趋势箭头突出变化，不使用大量装饰性小字。

底部区域：底部布置 KPI 指标卡、重点对象列表或运行明细表。表格包含名称、区域、实时数值、变化率、状态和更新时间，行高清晰，便于远距离阅读。

UI 细节：使用深色半透明模块化卡片、细蓝色描边、轻微内发光、统一圆角或小切角、清晰图表网格。文字使用现代无衬线中文字体，大标题、模块标题、数值和辅助说明形成明确层级。

渲染与输出：高端企业级数据可视化 UI，适度 3D 与 PBR 质感，柔和环境光，轻微 Bloom，细节丰富但不过度装饰。16:9 横向 4K 大屏，原生 3840×2160，一张完整屏幕，无浏览器边框、无设备模型、无水印。

避免：中央地图过大导致数据模块不足、电影概念图、过多粒子和霓虹、白色 SaaS、卡片尺寸混乱、文字过小、英文标题和明显乱码。
```

## 04. 行业写实数字孪生风格

![行业写实数字孪生风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F04-photoreal-digital-twin-4k.webp?projectId=make-project)

适合需要突出真实设备、场地、工艺和空间环境的数字孪生项目。写实场景必须占据主体，数据面板只负责解释和监控场景，不能把画面切割成普通数据卡片网格。

### 完整提示词

```text
企业级[行业名称]写实数字孪生运营大屏，标题为“[大屏标题]”。画面以照片级真实[中央载体]为主体，将真实设备、业务点位和实时数据覆盖层融合为一张正式的数字孪生监控界面。

场景与环境：使用符合行业实际的真实空间，完整展示地形、建筑、道路、设备、管线、仓储或生产设施。采用真实世界尺度和工程布局，材质具有金属、混凝土、玻璃、植被、道路和设备表面的细节。使用日出、日落、阴天或室内工业照明等具有层次的自然光环境，保持专业写实，不做纯概念艺术。

中央主体（写实数字孪生）：[中央载体]占画面至少 60%–70%，成为第一视觉中心。场景中清楚呈现[核心业务对象]及其空间关系，并使用克制的青绿色、蓝色或行业主色数据流连接关键节点。每个重点对象带有半透明点位标签，显示名称、实时数值、单位和运行状态。

顶部区域：顶部设置半透明深色标题栏，显示“[大屏标题]”、日期时间、区域或场站筛选。标题下方布置 5 个轻量 KPI，展示[关键指标]，包含图标、大数字、单位和变化趋势。KPI 不使用厚重卡片，不遮挡天空或重要场景。

左侧模块：在画面边缘设置“实时趋势”和“设备健康”等透明玻璃面板。趋势模块使用两到三条业务曲线；设备健康模块显示关键设备的健康度、在线率、负载率和状态灯。

右侧模块：设置“业务构成”和“告警事件”等透明玻璃面板。构成模块使用环形图和对象数值；告警模块使用时间、设备、等级、状态四列，突出重要和紧急事件。

底部区域：底部增加低矮横向运行明细表和实时环境指标。表格包含对象名称、类型、实时数值、当日累计、设备可用率和运行状态；环境指标根据行业显示温度、湿度、风速、电压、压力、流量或碳减排量。

UI 与场景融合：数据 UI 总面积不超过画面约 30%–35%。面板使用深色透明玻璃、细描边和轻微微光，放置在画面边缘或空白区，不遮挡关键设备。界面必须像真实数字孪生系统，而不是在照片上随意贴图表。

渲染与细节：高质量 PBR 材质、HDRI 环境光、Global Illumination、Ray Tracing、AO 环境遮蔽、真实阴影、电影级色彩和轻微景深。16:9 横向 4K 大屏，原生 3840×2160，中文界面，一张完整屏幕，无浏览器边框、无设备外框、无水印。

避免：把场景改成蓝色全息线框、普通二维 BI 网格、过多不透明卡片、面板遮住主体、空间布局不真实、低清模型、英文标题和明显乱码。
```

## 05. 明亮自然 GIS 风格

![明亮自然 GIS 风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F05-bright-natural-gis-4k.webp?projectId=make-project)

适合农业、水利、生态、气象和自然资源等重视地理空间与自然环境的场景。重点是浅色自然氛围、地形层次和地理科学感，不使用深色暗角或过强霓虹。

### 完整提示词

```text
企业级[行业名称]地理数据可视化大屏，标题为“[大屏标题]”。整体采用清新科技与自然主义结合的设计语言，以高精度地理沙盘、等高线和环境数据为核心，呈现干净、明亮、空灵而专业的 GIS 运营界面。

配色与氛围：主色为浅天蓝、青蓝、淡薄荷绿和渐变山脉色，少量金色、珊瑚橙或红色用于重要节点和告警。背景从浅蓝向米白柔和过渡，具有自然天空、远山、薄雾和极淡数字网格。整体明亮通透，无深色暗角、无黑色科技空间。

顶部区域：顶部采用现代轻量科技标题栏，显示“[大屏标题]”、日期时间、区域筛选、天气和数据更新时间。标题下方布置 4–5 个浅色 KPI，展示[关键指标]、同比环比和趋势。

左右 UI 布局：左右采用对称或平衡式模块化数据驾驶舱。卡片使用浅色半透明玻璃、柔和圆角、细青蓝描边和轻阴影，与中央自然沙盘融合。每侧至少包含 3 个完整模块。

右侧模块：聚焦业务运营与风险分析，包含计划完成柱状图、质量或健康雷达图、事件列表、风险等级、预警信息和对象画像。

底部区域：底部布置区域明细、监测站列表或业务统计表，包含名称、位置、实时数值、变化趋势、风险等级和更新时间。表格保持浅色、清晰、易读。

渲染与细节：C4D、Octane 或 Blender 高质量渲染，HDRI 柔和天光，轻微 Bloom，PBR 写实材质，细腻植被、地形纹理、水面反射和体积雾。16:9 横向 4K 大屏，原生 3840×2160，中文界面，无浏览器边框、无设备外框、无水印。

避免：深黑背景、赛博朋克霓虹、厚重深色卡片、只有风景没有数据、中央沙盘过度写实而缺乏 GIS 标记、英文标题和明显乱码。
```

## 06. 新中式东方美学风格

![新中式东方美学风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F06-new-chinese-oriental-4k.webp?projectId=make-project)

适合需要表达文化气质、公共属性和东方地域特征的行业。传统元素应作为结构、材质和背景语汇使用，避免堆砌龙凤、宫殿和复杂纹样。

### 完整提示词

```text
企业级[行业名称]新中式数据可视化驾驶舱，标题为“[大屏标题]”。设计深度融合现代数据平台、GIS 地图与东方古典美学，兼具正式业务系统的严谨和宋韵国风的典雅气质。

配色与氛围：整体采用高明度米白、浅青绿、玉石绿、青瓷绿与香槟金，少量朱砂红用于告警或重点。背景由浅米白向淡青绿渐变，融合极淡水墨山影、云雾、竹叶、宣纸肌理和细密数字网格。传统元素保持克制、留白和现代化，不使用浓重宫廷红金。

顶部区域：顶部标题栏融合古典匾额、卷轴或简化飞檐轮廓，使用玉石装饰和香槟金细线，显示“[大屏标题]”、日期时间、区域筛选和数据更新时间。标题栏古朴但简洁，不做繁复雕花。

中央核心（东方数字沙盘）：中央为高精度 3D 悬浮[中央载体]或 GIS 地图，呈翡翠绿与青瓷绿渐变，具有玉石、青瓷或浅浮雕质感。地图具有柔和厚度和阴影，边缘使用精细香槟金描边，分布金色定位节点、半透明数据标签、路线和状态光点。中央载体占画面约 35%–45%。

整体 UI：四周与底部使用浅色 Glassmorphism 毛玻璃卡片、半透明米白底、香槟金或浅绿细边框、柔和圆角和微弱发光。卡片中可见极淡宣纸纹理或云纹，但不能影响图表可读性。

左侧模块：聚焦资源总览、实时监测和区域状态，包含核心 KPI、趋势折线图、资源构成环形图、对象排行和环境指标。

右侧模块：聚焦业务分析、事件处置和风险预警，包含计划完成柱状图、雷达分析、事件列表、风险等级、处置进度和对象画像。

底部区域：底部设置业务明细、重点事项或区域排名，使用清晰表格、进度条和小型状态标签。数据字段包括名称、区域、实时值、累计值、状态和更新时间。

渲染与细节：Apple Vision Pro 式浅色玻璃层次结合 Microsoft Fluent Design 的柔和光影；C4D 或 Blender 高质量 3D，PBR 玉石和青瓷材质，Global Illumination，柔和漫反射，轻微 Bloom，8K 级视觉细节。16:9 横向 4K 大屏，原生 3840×2160，中文界面，无浏览器边框、无设备外框、无水印。

避免：传统符号堆砌、宫殿式繁复装饰、大面积红金、深黑科技背景、强霓虹 HUD、低信息量、只有地图没有业务模块、英文标题和明显乱码。
```

## 07. 极简玻璃 SaaS 风格

![极简玻璃 SaaS 风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F07-minimal-glass-saas-4k.webp?projectId=make-project)

适合强调现代、友好、轻盈和企业产品感的业务。大面积留白不等于删减信息，必须保留完整 KPI、图表、排行、状态和明细表。

### 完整提示词

```text
高级企业级[行业名称]可视化运营大屏，标题为“[大屏标题]”。整体采用 Apple Vision Pro 风格的企业级 SaaS 设计语言，呈现一张简洁、现代、专业且信息完整的正式产品界面。

配色与氛围：使用高明度霜白、浅天蓝、淡薄荷绿和柔和薰衣草紫渐变背景，具有通透明亮的空间感。背景加入极淡数字网格、柔和环境光和轻微层次变化，无深色暗角。颜色低饱和、克制、干净。

UI 语言：使用 Glassmorphism 半透明玻璃卡片、柔和圆角、精细浅色描边、轻阴影、磨砂质感和大面积但有秩序的留白。卡片之间保持统一间距和网格，不使用强发光、尖锐切角和黑色 HUD。

整体布局：完整 16:9 桌面大屏。顶部为现代标题栏、导航、时间和筛选；顶部下方设置 4–5 个 KPI；中部采用左右平衡的数据模块与小型中央沙盘；底部保留完整运行明细表。界面必须饱满完整，不能因为极简风格只留下少量卡片。

中央核心：中央展示精致 2.5D 或轻量 3D [中央载体]沙盘，包含[核心业务对象]、业务连接线、状态标签和少量发光数据流。模型约占中部 30%–40%，材质以白色、浅蓝、薄荷绿和透明玻璃为主，不使用深色电影场景。

顶部 KPI：显示[关键指标]，每个 KPI 包含彩色圆形图标、大数字、单位、同比环比和迷你趋势线。卡片尺寸统一，数字层级清晰。

左侧模块：包含趋势折线图、结构占比环形图和对象排行。模块标题、图例、坐标和单位清晰，图表使用蓝、青、绿、紫等柔和渐变色。

右侧模块：包含计划达成柱状图、设备或业务可用率、异常事件和状态统计。使用进度条、环形仪表和轻量状态标签，不使用密集暗色表格。

底部区域：设置完整的业务运行明细表，字段包含对象名称、关键数值、累计值、效率、状态和更新时间。表格采用浅色分隔、柔和行高和绿色状态胶囊。

渲染与细节：C4D、Octane 或 Blender 柔和 3D 渲染，HDRI 天光，PBR 玻璃与陶瓷材质，Global Illumination，Ray Tracing，轻微 Bloom 和柔和环境阴影。16:9 横向 4K 大屏，原生 3840×2160，中文界面，无浏览器边框、无设备外框、无水印。

避免：过度空白、只有 4 个 KPI 和 2 个图表、低信息量、黑色背景、赛博朋克、深色 FUI、强霓虹、手机布局、英文标题和明显乱码。
```

## 08. 数据决策 BI 风格

![数据决策 BI 风格 4K 参考图](/api/docs/data-visualization-style-reference%2Fassets%2F4k%2F08-data-decision-bi-4k.webp?projectId=make-project)

适合经营、财务、销售、供应链和管理决策场景。以指标、图表、表格、矩阵和结论为核心，弱化三维场景，但仍需保持专业视觉层次，不能退化为普通 Excel 截图。

### 完整提示词

```text
高级企业级[行业名称]数据决策 BI 大屏，标题为“[大屏标题]”。整体采用现代企业 BI 与专业 SaaS 数据产品视觉，强调经营分析、指标拆解、异常识别和决策建议，呈现一张正式可用的数据分析系统界面。

配色与氛围：使用高明度暖白、浅冷灰和极淡蓝色背景，搭配细腻分区线和柔和环境光。专业蓝为主色，绿色表示正向，橙色表示关注，红色表示异常，少量紫色用于辅助分类。色彩克制，背景保持清爽通透。

整体布局：完整 16:9 桌面大屏。顶部包含标题、日期、区域筛选和数据更新时间；第二行设置 6 个核心 KPI；中部布置 4 个主要分析模块；下部布置 4 个业务明细模块；最底部设置一排决策建议。使用严格多列网格、统一圆角和间距，信息密集但不拥挤。

顶部 KPI：展示[关键指标]，每个指标包含图标、大数字、单位、同比、环比和趋势箭头。重点指标使用蓝色，正向变化使用绿色，风险指标使用橙红色。

主要分析模块：
1. “经营摘要”：以计划值、实际值、完成率和同比变化展示核心业务概况。
2. “趋势分析”：使用分组柱状图叠加折线，比较计划、实际和历史数据。
3. “计划达成”：使用瀑布图或差异桥接图，说明正向贡献、负向影响和最终结果。
4. “结构构成”：使用堆叠柱状图或环形图，展示不同业务类型、区域或渠道的占比。

业务明细模块：
1. “对象排名”：使用可读表格与横向进度条展示排名、数值和完成率。
2. “偏差分析”：展示计划值、实际值、偏差值、偏差率和小型正负柱形。
3. “可用率矩阵”：使用热力矩阵展示[核心业务对象]在多个指标上的健康程度。
4. “异常矩阵”：使用时间、对象、异常类型、级别、状态和持续时间组成清晰事件表。

底部决策建议：根据数据结果生成 4 条简短建议，例如优化计划、降低损耗、关注设备健康、提升资源调度或强化异常管理。每条建议包含图标、短标题和一行说明，不能出现大段无法阅读的小字。

UI 语言：浅色卡片、精细描边、统一圆角、严谨网格、清晰数字层级和现代无衬线中文字体。弱化或取消大型 3D 沙盘，让图表、表格和分析结论成为视觉中心，但保留适度图标、渐变和环境光，避免像原始表格截图。

输出要求：16:9 横向 4K 大屏，原生 3840×2160，中文界面，标题、大数字、图例、单位和状态清晰；一张完整屏幕，无浏览器边框、无设备外框、无水印。

避免：文字堆成噪点、图表过密无法阅读、表格边框过重、大面积空白、中央 3D 模型抢占空间、黑色科幻背景、赛博朋克、英文标题和明显乱码。
```

## 使用建议

- 同一行业需要比较风格时，保持行业、标题、指标和业务对象一致，只替换上述视觉风格提示词。
- 不同行业复用同一风格时，只替换变量和业务模块内容，不删减配色、布局、中央载体、卡片语言、光照和渲染描述。
- 图片生成模型对小号中文的稳定性有限。样张适合用于风格确认；正式页面中的标题、图表、表格和数据建议通过 HTML/CSS 或可视化组件重建。
- 如果生成结果趋同，优先强化“中央载体、卡片语言、数据密度和光照方式”的差别，而不是继续减少信息模块。

# PRD 计划

## 状态定义

- `待确认`：范围或关键问题尚未得到用户确认。
- `待编写`：范围已确认，可以进入 `write-prd`。
- `编写中`：当前正在生成或更新。
- `待评审`：文档已完成，等待用户评审。
- `已完成`：用户已确认当前版本。
- `阻塞`：依赖、来源或授权不足，暂时不能继续。

## 执行入口

每次执行说明包含：

- 只执行状态为 `待编写` 的任务，开始时改为 `编写中`。
- 读取 `PROJECT.md`、`SOURCES.md`、`PLAN.md`。
- 读取当前任务列出的 `src-001` 页面 JSON、截图和页面索引。
- 使用 `templates/prd.md`，通过 `write-prd` 写入目标路径。
- 只将页面、交互定义和用户决策能够证明的内容写为事实；未触发状态、后台规则和建议分别标为待确认或建议。
- 完成后把任务改为 `待评审`，并同步 `PROJECT.md` 的开放问题和 PRD 目录。

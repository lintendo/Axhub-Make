## 背景与问题

飞书企业管理后台在“安全”导航下集中呈现策略中心、安全中心、成员权限、账号安全、终端安全、网络安全、链接安全、数据分类、数据保护及部署与加密能力。当前产品缺少一份可追溯的现状规格，用于区分当前登录视角下真正可见的管理页面、可继续进入的设置入口、版本升级介绍和新版体验介绍，避免把营销文案或入口误写成已开通、已配置或已生效的安全能力。

本文基于 2026-08-14 对当前租户登录视角的页面采集，反推页面 028-039 共 12 个一级页面。证据来自 `src-001` 的结构化页面提取与同名桌面截图，并形成四类当前状态：策略管理等页面为升级/增值介绍；安全概览、成员异常、文档异常三个路由展示同一套安全中心新版介绍；成员权限同时展示设置入口和高级安全服务升级引导；链接安全的结构化提取展示空数据管理页。

链接安全存在采集时点差异：同名 JSON 已提取到概览、近 7 天统计、排行、点击日志、筛选及“暂无数据”，而截图停留在加载骨架。因此本文可以定义结构化证据明确的页面信息和空态，但不把该截图作为加载完成后的完整视觉布局依据。本文不扩写升级/体验后的页面、各设置项详情、安全检测算法、策略字段、权限规则、告警生命周期、数据保护效果或后台实现。

## 目标与成功标准

### 产品目标

1. 建立安全治理一级页面的现状基线，说明每个入口当前属于介绍、受限、可配置入口还是数据管理页面。
2. 让有权管理员可以识别当前可继续进入的成员权限和链接安全入口，并看到对应的页面说明、结构和当前状态。
3. 准确记录策略中心、安全中心及账号/终端/网络/数据安全等页面展示的产品方向与升级动作，不把介绍内容写成已开通能力。
4. 明确链接安全的默认统计周期、统计分区、日志字段、筛选入口及空数据状态，同时保留截图加载状态与结构化提取之间的证据差异。
5. 为后续合规与审计 PRD 提供安全导航上下文，并隔离未展开交互、版本限制、空数据和单一管理员视角造成的证据缺口。

### 成功标准

1. 12 个页面均可从企业管理后台“安全”导航定位，并呈现与本文状态分类一致的页面内容。
2. 策略管理、账号安全、终端安全、网络安全、数据分类、数据保护、部署与加密被明确验收为当前可见的介绍/升级状态，而非已验证的配置能力。
3. 安全概览、成员异常、文档异常三个独立路由均被记录为当前共用的新版介绍状态，不据此断言异常列表、详情或处置流程已可用。
4. 成员权限能够区分已显示的六个设置入口、高级安全服务升级内容及当前升级提示；各入口后的实际配置不作为本次通过条件。
5. 链接安全能够按结构化证据验证近 7 天概览、趋势分区、两类空排行、点击日志筛选/表头及日志空态；视觉验收不超出当前加载骨架截图能证明的范围。
6. 未采集的升级、立即体验、了解更多、策略设置、配置详情、有数据日志、异常处置、错误状态和其他角色视角不被当作已确认能力验收。

## 用户、角色与场景

| 用户/角色 | 触发场景 | 核心任务 | 当前证据边界 |
| --- | --- | --- | --- |
| 企业超级管理员 | 评估企业安全治理能力和当前可用范围 | 浏览安全导航；查看可见设置入口、介绍内容、升级/体验动作和链接安全概览 | `prd-01` 只证明超级管理员角色存在且显示“全部权限”，未证明本次采集账号的具体角色或逐页鉴权 |
| 具有安全模块访问权限的管理员 | 按职责查看安全治理页面 | 进入被授权的安全页面，查看介绍、成员权限入口或链接安全当前状态 | 这是按访问条件描述的使用者，不代表已观察到同名角色；授权方式、可见范围及无权限结果未采集 |
| 具有成员权限页访问权限的管理员 | 维护组织、成员、文档或多维表格相关设置 | 从成员权限页进入对应设置入口 | 这是按访问条件描述的使用者；本次只确认入口和用途说明，规则、继承、例外与保存结果未观察 |
| 具有链接安全页访问权限的管理员 | 查看链接风险概览和点击日志 | 查看近期趋势分区、排行和日志，使用可见筛选入口 | 这是按访问条件描述的使用者；风险记录、有数据列表和处置动作均未展开 |

主要场景包括：

1. 管理员进入策略管理，查看策略中心新版介绍、能力亮点和联系客服升级入口，判断当前视角未进入真实策略配置页。
2. 管理员分别从安全概览、成员异常或文档异常进入安全中心，当前均看到“安全中心全新上线”介绍，并可选择“立即体验”；本文不触发该动作。
3. 管理员进入成员权限，按可见性设置、文件文档管理和多维表格管理浏览设置入口，同时识别高级安全服务升级区和成员字段可见范围升级提示。
4. 管理员进入账号、终端、网络、数据分类、数据保护或部署与加密页面，查看当前介绍内容、能力卡片和升级/了解更多入口。
5. 管理员进入链接安全，查看默认近 7 天的风险趋势分区、风险链接排名、访问成员排名和点击日志；当前两类排行和日志均无记录，趋势区未提取到数据点或数值。

## 范围

### 本次包含

- 策略管理：策略中心新版介绍、联系客服升级入口及脚本化配置、分级处置、内容感知、动态条件、行业模板、快速响应等可见介绍内容。
- 安全中心：安全概览、成员异常、文档异常三个路由及当前共用的新版介绍、立即体验入口、文档数据和行为数据两类介绍内容。
- 成员权限：组织架构可见范围、成员字段可见范围、云文档设置、云文档权限默认值管理、云文档信息流通设置、多维表格设置六个入口；高级安全服务升级区和当前升级提示。
- 账号安全：当前增值介绍、联系客服升级、SSO 账号登录、登录方式、登录密码、两步验证、登录有效期和多端同登等介绍项。
- 终端安全：当前增值介绍、联系客服升级、移动端文件加密和粘贴保护等介绍项。
- 网络安全：当前增值介绍、联系客服升级及 IP 围栏管理介绍项。
- 链接安全：策略入口、概览、默认近 7 天周期、风险量级趋势、两类排行、点击日志、搜索/筛选、表头及空数据状态。
- 数据分类：当前增值介绍、联系客服升级、数据发现和内容匹配规则相关介绍。
- 数据保护：当前增值介绍、联系客服升级、密级标签、全局水印和水印设置等介绍项。
- 部署与加密：数据私有化、自主密钥等当前介绍内容及升级入口。
- 当前可见的版本受限、新版体验、可配置入口、升级引导、空数据和加载骨架状态。

### 不在本次范围

- 联系客服后的升级咨询、报价、购买、开通、审核、支付和套餐生效结果。
- 点击“立即体验”后的开通条件、授权确认、数据迁移、页面变化及安全中心真实业务能力。
- 策略中心开通后的策略创建、脚本语法、模板内容、优先级、命中、处置、生效范围、发布、回滚和冲突规则。
- 安全中心的成员/文档异常识别逻辑、异常等级、告警列表、详情、筛选、标注、导出、处置和生命周期。
- 成员权限六个设置入口后的字段、对象选择、继承/覆盖、优先级、校验、保存、生效、回滚与无权限规则。
- 搜索权限、沟通协作、对外沟通权限、文件操作权限等高级安全能力的实际配置与生效结果；当前仅记录升级介绍。
- 账号、终端、网络、数据分类、数据保护、部署与加密介绍项的真实配置页、适用端、作用范围、算法、密钥管理、加密过程和保护效果。
- 链接安全策略详情、检测算法、风险类型枚举、日志详情/操作、导出、分页、有数据状态、处置结果及统计口径。
- 通用加载失败、网络异常、权限拒绝、配置提交失败、并发冲突和后台数据库/API Schema/审计实现。

## 用户故事

1. 作为企业管理员，我希望识别每项安全能力当前是介绍页、体验入口、配置入口还是数据页，从而准确判断当前可操作范围。
2. 作为安全管理员，我希望从策略管理和安全中心查看当前产品说明及升级/体验入口，从而决定是否继续咨询或体验，而不误认为策略或告警已启用。
3. 作为组织信息管理员，我希望从成员权限页找到组织架构与成员字段可见范围入口，从而继续维护成员信息的可见边界。
4. 作为文档安全管理员，我希望从成员权限页找到云文档和多维表格相关设置入口，从而进入对应的全局设置任务。
5. 作为安全管理员，我希望查看账号、终端、网络、数据分类、数据保护及部署与加密的当前介绍内容，从而了解当前页面给出的安全治理方向和升级路径。
6. 作为链接安全管理员，我希望查看近期风险趋势、排行和点击日志，并按关键词、风险类型、成员和时间筛选，从而了解当前是否存在可见风险记录。

## 数据模型

本节描述页面上对管理员有意义的业务对象，不代表数据库或 API 设计。

| 业务对象 | 已观察字段/属性 | 对象关系与当前状态 |
| --- | --- | --- |
| 安全能力介绍 | 页面名称、介绍文案、能力亮点、升级/体验动作、了解更多入口 | 对应一个安全导航页面；多数页面当前只证明介绍内容和动作入口可见，不证明能力已开通 |
| 安全中心入口 | 路由名称、页面面包屑、统一新版介绍、立即体验入口 | 安全概览、成员异常、文档异常为三个独立路由，当前展示同一套介绍内容；真实概览与异常对象未观察 |
| 成员权限设置入口 | 分组、设置项名称、用途说明 | 六个入口分属可见性设置、文件文档管理、多维表格管理；入口后的配置对象和规则未观察 |
| 高级安全服务介绍 | 能力名称、用途说明、了解更多、联系客服升级 | 当前可见搜索权限、沟通协作、对外沟通权限、文件操作权限；不代表当前套餐可配置 |
| 链接安全概览 | 统计周期、风险链接点击量级趋势、风险链接排名、访问风险链接成员排名 | 结构化证据中默认周期为近 7 天，两类排行均为暂无数据；统计指标口径未观察 |
| 链接点击日志 | 关键词、风险类型、点击人、点击时间、链接、操作 | 当前日志无数据；筛选可见，但风险枚举、行详情和操作内容未展开 |
| 数据分类介绍 | 数据发现、内容匹配规则相关说明 | 当前为升级介绍；数据发现任务、敏感信息类型、规则和分类结果未观察 |
| 数据保护介绍 | 密级标签、全局水印、水印设置 | 当前为升级介绍；标签、策略、水印范围及生效状态未观察 |
| 部署与加密介绍 | 数据私有化、自主密钥及用途说明 | 当前为升级介绍；存储位置、密钥对象、加解密流程和实际状态未观察 |

## 业务规则

| 规则 ID | 条件 | 可见动作/结果 | 限制与证据边界 |
| --- | --- | --- | --- |
| `SG-R01` | 管理员打开策略管理 | 页面展示“策略中心全新上线”、能力亮点及“联系客服升级”入口 | 当前为升级介绍页；介绍内容不证明策略配置、模板或处置已可用 |

| `SG-R05` | 当前成员权限页出现升级提示 | 提示原“名片页字段可见范围”已升级为基础规则，并提供“我知道了”关闭动作 | 未关闭提示，不定义再次出现、阅读状态持久化或升级后的规则变化 |
| `SG-R06` | 管理员打开账号安全 | 页面展示账号安全介绍、联系客服升级以及 SSO、登录方式、登录密码、两步验证、登录有效期、多端同登等介绍项 | 不定义各项配置、例外、验证、会话或强制登出规则 |

- 安全产品文案、能力分组或升级策略变化会改变介绍项名称与页面归属，不应将当前介绍文案固化为后台规则。

## 风险与依赖

- **风险：介绍内容被误判为已开通能力。** 多数页面详细描述安全价值和能力名称，但当前没有真实配置页、业务数据或生效证据；若不保留状态分类，会扩大产品现状范围。
- **风险：安全中心真实页面缺失。** 三个路由当前共用新版介绍，无法定义成员异常、文档异常和安全概览的业务对象、字段、状态与流程。

- **风险：权限和套餐视角单一。** 当前只证明采集账号可达这些页面，无法区分套餐、产品开关和管理员鉴权对页面状态的具体影响。

- **依赖：** 本文依赖 `prd-01` 的企业/管理员上下文和 `prd-02` 的成员、组织、用户组、字段对象；后续 `prd-08` 可引用安全导航与作用范围边界，但日志、权限、数据保留、内容合规和隐私设置仍须以页面 040-044 的自身证据为准。

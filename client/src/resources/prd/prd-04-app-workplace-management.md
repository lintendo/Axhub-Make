## 背景与问题

飞书企业管理后台通过“工作台”和“API 用量情况”承载应用审核、已安装应用管理、工作台展示设置、定制工作台介绍及基础 API 调用明细查看能力。当前产品缺少一份可追溯的现状规格，用于区分已经可见的管理页面、仅存在的后续操作入口，以及当前套餐视角下的增值能力介绍。

本文基于 2026-08-14 对当前租户登录视角的页面采集，反推以下 5 个一级页面的现状：应用审核、应用管理、工作台设置、定制工作台和基础 API 调用次数。结论只来自 `src-001` 的页面 011-015 结构化提取与同名桌面截图，不扩写未进入的审核规则、飞书审批配置、应用创建/获取/配置、管理规则、工作台规则、二级页签、升级流程或套餐内部规则。

当前应用审核和基础 API 调用明细均为空态，已安装应用列表有数据；工作台设置仅观察到“管理员推荐”默认页及添加规则入口；定制工作台展示增值能力介绍、升级入口与套餐对比，不证明定制能力已向当前企业开放。

## 目标与成功标准

### 产品目标

1. 为管理员提供应用审核记录的查询入口，并在无待审核应用时给出明确空态和后续入口。
2. 集中展示当前企业的已安装应用，使管理员能够通过筛选、搜索和列表信息定位待管理应用。
3. 提供工作台推荐、自定义分组和应用展示的设置入口，并明确当前可见的推荐去重说明。
4. 在当前版本视角下展示定制工作台的能力介绍、升级咨询入口和套餐对比，而不将介绍内容误判为已开通能力。
5. 提供按日期和应用查看基础 API 调用明细的页面，并明确页面展示的数据时效口径。
6. 明确空数据、动态列表、版本限制及未展开交互的证据边界，为后续评审和补采提供依据。

### 成功标准

1. 5 个页面均可从企业管理后台定位，并呈现本文列出的核心结构、状态、说明和操作入口。
2. 应用审核空态、已安装应用有数据、推荐规则未展开、定制工作台为增值介绍页、基础 API 调用明细为空等当前状态均有可区分的用户反馈。
3. 应用管理页能够展示筛选、搜索、应用列表字段和当前可见的配置/获取入口；工作台设置页能够展示 3 个页签及添加推荐规则入口。
4. 定制工作台的模板、小组件、编辑器、多端适配等内容只作为页面介绍文案记录，不作为当前企业可执行能力验收。
5. 未采集的配置、创建、获取、审核、规则、升级、提交、错误和有数据详情不被当作已确认能力验收。

## 用户、角色与场景

| 用户/角色 | 触发场景 | 核心任务 | 当前证据边界 |
| --- | --- | --- | --- |
| 企业超级管理员 | 企业应用与工作台治理 | 查看待审核应用、已安装应用、工作台设置、定制工作台状态和 API 调用明细 | `prd-01` 证明该角色显示“全部权限”；本文未验证 5 个页面的逐项鉴权规则 |
| 具有工作台模块权限的子管理员 | 按授权职责处理应用或工作台设置 | 搜索应用、查看可用范围，从可见入口进入配置或推荐规则设置 | 权限组合、作用范围和无权限结果未采集 |
| 应用管理相关管理员 | 日常定位和维护企业应用 | 使用付费类型、开发者、可用范围和应用名/App ID 条件查找已安装应用 | 页面未命名独立系统角色；“配置”等后续操作均未进入 |
| 用量查看相关管理员 | 查看基础 API 调用情况 | 选择日期范围、搜索应用并查看应用、开发者和调用次数 | 当前明细为空，无法证明有数据状态、导出或详情能力 |

主要场景包括：

1. 管理员进入应用审核页，搜索待审核应用；当没有记录时查看空态，并按需要进入审核规则或飞书审批配置入口。
2. 管理员进入应用管理页，按付费类型、开发者、可用范围或应用名/App ID 定位已安装应用，并从当前可见的配置入口继续管理。
3. 管理员从应用管理页进入获取应用、创建应用或设置管理规则入口；本文只确认入口存在。
4. 管理员进入工作台设置，查看“管理员推荐”规则说明，并从添加推荐规则入口继续；也可看到自定义分组和应用展示页签。
5. 管理员打开定制工作台，了解增值能力、案例和套餐对比，或选择立即升级、升级咨询。
6. 管理员选择日期范围并按应用名称查询基础 API 调用明细；当前无记录时查看空态。

## 范围

### 本次包含

- 应用审核：应用名模糊搜索、审核记录列表字段、设置审核规则入口、通过飞书审批进行应用审核的配置提示、创建应用/了解更多空态说明。
- 应用管理：已安装应用列表、付费类型/开发者/可用范围筛选、应用名或 App ID 搜索、应用列表字段、当前可见的配置与停用状态，以及获取应用、创建应用、设置管理规则入口。
- 应用管理页中的精选推荐区域：应用、开发者和操作字段，付费标识、获取入口及分页/引导等当前可见内容。
- 工作台设置：管理员推荐、自定义分组、应用展示 3 个页签；添加推荐规则入口；推荐项默认展示位置和跨规则去重说明。
- 定制工作台：增值版本介绍、立即升级与升级咨询入口、功能亮点/客户案例/套餐对比内容分区。
- 基础 API 调用次数：日期范围、应用名称搜索、应用/开发者/调用次数字段、数据时效说明和当前空态。
- 当前可见的默认态、有数据态、空数据态、页面引导和增值介绍状态。

### 不在本次范围

- 应用审核规则、直属上级/部门负责人参与审核的实际配置字段、审核节点、审批人解析、审核状态流转、操作权限和异常处理。
- 飞书审批中的应用审核配置、审批单字段、通知、撤回、转交、同意/拒绝结果和两端数据同步。
- 应用获取、创建、配置、停用/启用、卸载、授权范围变更及设置管理规则的表单、校验、生命周期和错误处理。
- 付费应用的价格、购买、试用、续费、退款和套餐规则；开发者联系方式不作为业务规则。
- 应用来源、付费类型、开发者和可用范围筛选的完整枚举、组合筛选逻辑、搜索匹配与重置规则。
- 工作台推荐规则的名称、目标范围、应用/链接选择、排序、优先级、保存、冲突与生效规则；当前未展开规则配置。
- 自定义分组、应用展示页签及“更多”入口后的页面内容和设置行为。
- 定制工作台的模板、小组件、编辑器、开发能力、发布、终端适配配置和真实工作台效果；这些只在介绍文案中出现。
- 定制工作台套餐对比中的具体版本资格、额度、计费、购买人数和随套餐变化的能力规则。
- 基础 API 调用明细的统计口径、API 分类、时区、应用身份映射、调用失败计数、导出、钻取及有数据状态。
- 后端数据库、API Schema、鉴权算法、审核实现、计费实现及任何行业惯例补充。

## 用户故事

1. 作为应用管理相关管理员，我希望搜索待审核应用并看到当前空态，从而判断当前是否存在需要处理的应用审核任务。
2. 作为应用管理相关管理员，我希望按付费类型、开发者、可用范围或应用名/App ID 查找已安装应用，从而定位需要继续配置的应用。
3. 作为企业管理员，我希望看到获取应用、创建应用和设置管理规则入口，从而进入相应的后续管理任务。
4. 作为工作台管理员，我希望查看管理员推荐说明并进入添加推荐规则，从而开始设置成员工作台中的推荐内容。
5. 作为企业管理员，我希望明确定制工作台当前是增值介绍状态，从而选择升级或咨询，而不会误认为当前套餐已经开放配置。
6. 作为用量查看相关管理员，我希望按日期范围和应用名称查看基础 API 调用明细，从而了解应用调用情况和页面数据时效。

## 能力与信息架构

```text
企业管理后台
├── 工作台
│   ├── 应用审核
│   │   ├── 待审核应用列表（当前为空）
│   │   ├── 设置审核规则（仅确认入口）
│   │   └── 飞书审批配置（仅确认提示与入口）
│   ├── 应用管理
│   │   ├── 已安装应用（当前有数据）
│   │   ├── 获取应用（仅确认入口）
│   │   ├── 创建应用（仅确认入口）
│   │   ├── 设置管理规则（仅确认入口）
│   │   └── 精选推荐（当前可见内容区）
│   ├── 工作台设置
│   │   ├── 管理员推荐（当前）
│   │   ├── 自定义分组（仅确认页签）
│   │   └── 应用展示（仅确认页签）
│   └── 定制工作台（增值介绍页）
│       ├── 功能亮点
│       ├── 客户案例
│       └── 套餐对比
└── API 用量情况
    └── 基础 API 调用次数
        └── 基础 API 调用明细（当前为空）
```

应用审核面向待处理记录及审核配置入口；应用管理面向当前已安装应用和应用获取入口；工作台设置面向推荐、分组与展示配置入口；定制工作台当前只提供增值能力介绍和升级入口；基础 API 调用次数提供独立的用量查看页面。入口存在不代表其后续流程已验证，介绍页内容也不代表当前企业已经获得对应能力。

## 数据模型

本节描述页面上对管理员有意义的业务对象，不代表数据库或 API 设计。

| 业务对象 | 已观察字段/属性 | 对象关系与当前状态 |
| --- | --- | --- |
| 应用审核记录 | 应用、申请时间、版本号、操作 | 记录对应一个待审核应用；当前列表为空，审核状态枚举和操作未观察 |
| 已安装应用 | 应用名称、应用说明、付费标识（部分应用）、应用来源、开发者、可用范围、操作 | 归属于当前企业的已安装应用列表；当前有数据，可见“全员可用”“团队管理员停用”等范围/状态表达及部分“配置”入口 |
| 推荐应用 | 应用名称、付费标识、开发者、操作 | 位于应用管理页的精选推荐内容区；当前可见“获取”入口，推荐来源、排序和获取结果未观察 |
| 工作台推荐规则 | 推荐应用或链接、默认展示位置、跨规则重复项处理说明 | 当前只观察到添加入口和说明；页面未显示已配置规则详情，规则字段、作用范围和生命周期未观察 |
| 定制工作台能力 | 产品介绍、功能亮点、客户案例、套餐对比 | 当前为增值介绍页；模板、小组件、编辑器及多端能力仅来自介绍文案，实际配置对象未观察 |
| 基础 API 调用明细 | 日期范围、应用、开发者、调用次数 | 当前列表为空；日期和应用名称用于查询，统计对象、口径和有数据行未观察 |

## 权限与作用范围

1. 本次采集账号可以访问本文覆盖的 5 个页面及其当前可见入口，但该事实不能证明所有企业管理员具有相同的查看或操作权限。
2. `prd-01` 只证明超级管理员当前显示“全部权限”；本文未观察工作台模块是否存在独立管理员角色，也未验证子管理员的页面、应用或字段级授权范围。

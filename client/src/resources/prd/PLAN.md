# PRD 计划

## 状态定义

- `待确认`：范围或关键问题尚未得到用户确认。
- `待编写`：范围已确认，可以进入 `write-prd`。
- `编写中`：当前正在生成或更新。
- `待评审`：文档已完成，等待用户评审。
- `已完成`：用户已确认当前版本。
- `阻塞`：依赖、来源或授权不足，暂时不能继续。

## 执行入口

每次执行说明包含：

- 只执行状态为 `待编写` 的任务，开始时改为 `编写中`。
- 读取 `PROJECT.md`、`SOURCES.md`、`PLAN.md`。
- 读取当前任务列出的来源文件。
- 使用 `write-prd` 写入目标路径。
- 统一使用项目模板 `templates/prd.md`。
- 只写已观察事实；受限功能、未触发交互和空数据详情保持为边界或开放问题。
- 对企业编号、联系人、手机号、邮箱等具体值脱敏。
- 完成后更新任务状态和开放问题。

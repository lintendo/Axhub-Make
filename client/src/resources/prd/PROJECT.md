# 飞书企业管理后台（Axhub 租户现状）

## 产品概览

- 一句话定位：面向企业管理员的一站式管理后台，集中管理组织、应用、资源与费用、安全合规、数据分析和企业级配置。
- 产品背景：本产品信息基于 2026-08-14 对 Axhub 飞书租户管理后台的 63 个一级可达页面进行现状反推；仅描述当前登录视角能够证明的产品事实。
- 产品目标：为企业管理员提供统一的企业管理入口，并按管理员权限和企业套餐开放对应的管理、治理和数据能力。

## 用户与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 企业超级管理员 | 企业初始化、组织治理和全局配置 | 管理企业信息、管理员角色、组织架构、应用、资源、安全与数据能力 |
| 具有模块权限的子管理员 | 按职责处理指定业务模块 | 在授权范围内管理成员、应用、会议室、费用、安全、报表或企业配置 |
| 人事管理员等专项管理员 | 处理专项管理任务 | 使用人事管理模式或其他被分配的业务权限完成专项配置 |

## 产品范围

### 包含

- 企业概览、全局导航、企业信息和管理员治理。
- 组织架构、成员、角色、单位、用户组、成员字段、人事配置和关联组织。
- 会议室资源与会议设备运维。
- 应用审核、应用管理、工作台配置、定制工作台和基础 API 用量。
- 产品订阅、权益、订单、发票、支付通知和 AI 使用管理。
- 存储容量、清理和上限管理。
- 安全策略、安全中心、成员/账号/终端/网络/链接/数据安全、部署与加密。
- 日志与权限审计、数据保留、内容合规和隐私设置。
- 员工与各产品功能使用数据报表。
- 品牌、客户端功能和企业文化配置。

### 不包含

- 飞书客户端中的成员侧功能与日常协作体验。
- 当前套餐或权限无法进入的增值功能内部页面、字段和规则。
- 未触发的新建、编辑、删除、提交、错误校验和有数据详情状态。
- 后端数据库、API Schema、权限算法、计费算法和审计实现。
- 产品优化建议、未来版本、竞品能力或行业惯例补充。

# Qwen 截图还原首版 HTML 设计

## 目标

验证“RapidOCR 文字预处理 + Qwen 3.7 Plus 视觉结构分析”能否直接产出一份可评审、可编辑的移动端 HTML 首版，并在保持视觉接近原图的前提下缩短后续人工和 AI 调整时间。

本次只生成本地验证产物，不修改正式原型、主规格或截图还原核心流程。

## 输入与输出

- 输入截图：`municipal-government-services-home/source.png`，原始尺寸 863 × 1823。
- 结构输入：现有 Qwen 3.7 Plus `component-tree.json`。
- 文字输入：现有 RapidOCR 识别结果，并以原图人工可见内容校验。
- 输出目录：`.local/vision-model-benchmark/results/municipal-government-services-home/qwen3.7-plus/`。
- 主要输出：`generated.html`、局部图片素材、同尺寸渲染截图和浏览器验证结果。

## 页面还原策略

页面按约 432 × 912 CSS 像素的移动端视口实现，对应原图 2 倍像素密度，并在较窄移动端宽度下等比适配。

以下内容使用语义化 HTML/CSS：

- 状态栏、标题栏与城市选择；
- 搜索入口；
- 横幅文案与轮播圆点；
- 四个快捷入口；
- 八个业务分类入口；
- 热门服务卡片；
- 通知公告列表；
- 固定底部导航。

徽章、消息图标、业务图标、横幅建筑等视觉复杂且不适合首版重绘的内容，允许从原图局部裁切为本地素材。素材只承担图形表现，按钮、文字、布局和交互仍由 HTML 表达。

## 交互边界

首版提供轻量、可验证的交互反馈：

- 搜索框可以聚焦和输入；
- 城市选择器可以展开简单菜单；
- 轮播圆点可以切换选中状态；
- 快捷入口、业务入口和热门服务卡片可点击并显示反馈；
- 底部导航可以切换选中项。

不实现真实路由、网络请求、业务数据加载或完整轮播内容。

## 视觉与结构验收

- 页面主要区块的顺序、宽度、间距和高度应与原图一致；
- 所有可见中文文案应正确，不能依赖整图背景伪装；
- 局部素材加载成功且不覆盖 HTML 文案；
- 432 × 912 视口下无横向溢出，底部导航固定；
- 页面加载无控制台错误，关键交互可执行；
- 生成同尺寸截图，供用户与原图直接对照评审。

## 非目标

- 不使用 SAM2 进行全页分割；
- 不把整张截图作为页面背景；
- 不追求一次生成即成为最终规格或生产代码；
- 不把本次临时结果提交到正式原型目录。

## 后续判断

如果首版视觉和结构达到可评审水平，则把该步骤固化为截图预处理脚本的 HTML 生成阶段；如果主要差异集中在素材和细节，则交给后续 AI 评审调整，而不是重新进行整页结构识别。

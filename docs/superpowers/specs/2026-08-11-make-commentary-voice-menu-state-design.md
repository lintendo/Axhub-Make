# Make Commentary 语音助手菜单状态设计

## 目标

把批注工具栏“更多”菜单中的语音入口改成固定功能名称和图标状态，避免通过“显示/隐藏”两个动作词表达同一个开关。

## 交互设计

- 菜单文案始终为“语音助手”。
- 语音助手关闭时，左侧显示麦克风图标。
- 语音助手开启时，左侧替换为勾选图标，同时沿用菜单现有的选中背景和前景色。
- 菜单项使用 `menuitemcheckbox` 和 `aria-checked` 暴露开启/关闭状态。
- 点击行为保持不变：继续调用现有 `onToggleCommentaryVoice`，并在切换前关闭“更多”菜单。
- 入口仍只在 Quick Edit 激活且宿主提供切换回调时显示。

## 方案选择

采用“关闭显示麦克风、开启显示勾选”的方案，与项目中已有 AI 菜单状态项保持一致。

未采用：

- 麦克风图标常驻、右侧额外显示勾选：会增加菜单项视觉占用。
- 使用“开启语音助手/关闭语音助手”动态文案：仍通过动作词切换，不符合固定“语音助手”文案的要求。

## 实现边界

只修改 `PresentationToolbar` 的语音菜单项及对应回归测试。不改语音助手挂载、连接、配置预检、会话状态或生命周期逻辑。

## 验证

- 源码回归测试验证固定文案、麦克风图标、勾选状态、`aria-checked` 和现有点击回调。
- 运行 Commentary voice visibility 与 Presentation toolbar 聚焦测试。

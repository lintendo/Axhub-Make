# 画布 Agent 供应商与 AI 设置一致

## 目标

画布 AI 输入框的“供应商”菜单始终展示 AI 设置中定义的全部本地 ACP Agent，而不是仅展示 Claude Code、Codex 和 OpenCode。当前设置中的所有供应商都应可选，即使本机尚未检测到对应命令。

## 当前问题

`CanvasGenerationComposer` 定义了自己的固定三项回退列表。AI 设置则从 `ACP_PROVIDER_OPTIONS` 读取完整供应商定义。两份名单独立维护，导致画布菜单遗漏 Cursor、Qoder、CodeBuddy、Reasonix 与 Grok Build 等设置项。

## 设计

- 将画布侧默认供应商选项改为从 `ACP_PROVIDER_OPTIONS` 派生，并保持其定义顺序与标签。
- 保留当前默认供应商选择规则：使用项目已配置的默认 Agent；未配置时使用 Codex。
- 运行时上下文提供供应商列表时继续优先使用该列表；缺失时回退到共享完整列表。
- 不按本机安装状态、版本检测或连接状态过滤菜单项。可用性仍由既有 ACP 运行时能力和执行反馈处理。

## 测试

- 断言画布默认菜单等于共享完整供应商列表。
- 断言运行时没有提供列表时，回退结果也等于共享完整列表。
- 断言当前选中的合法供应商仍被保留，避免状态切换后菜单丢失已选项。

## 非目标

- 不改变 AI 设置中的供应商定义、安装检测或默认 Agent 保存逻辑。
- 不增加服务端接口或运行时权限筛选。

# 画布视口 AI 生成与有界会话

## 目标

用户点击画布底部 AI 按钮后，系统先把浏览器中的最新画布保存到磁盘，再将当前可见视口截图和视口坐标作为视觉上下文交给内置 AI。AI 不使用 Canvas MCP，而是直接读取并修改对应的 `.excalidraw` 文件，把结果放在当前视图附近。每个画布绑定一个有限期会话，避免长期连续对话不断触发上游上下文压缩。

## 已确认的约束

- 不增加“视觉推理助手”角色设定，也不重复声明模型已有的图像识别能力。
- 不在 Excalidraw 画布中插入占位图或任务状态卡；状态只在底部控件中体现。
- 结果不经过前端固定尺寸/占位符落位。Agent 使用文件工具直接修改目标 `.excalidraw` JSON。
- 首选当前可见内容右侧的空白区域，其次为下方；不得覆盖既有内容。
- 每个画布同一时间只允许一个视口 AI 任务。
- 提交前必须先完成当前浏览器画布的服务端保存，确保磁盘文件包含用户刚画完的内容；保存失败时不启动 AI。
- 截图是请求时刻的视觉快照；写回前 Agent 必须重新读取目标文件，保留文件中的已有内容。
- 若截图和目标文件都无法推断明确意图，Agent 只提出一个简短澄清问题，不写入猜测性内容。
- 视口 AI 请求不挂载 `axhub-canvas` MCP server，也不修改 ACP UI 的通用审批行为。

## 请求与提示词

点击时客户端按以下顺序准备请求：

1. 若画布存在未保存内容，立即执行现有服务端保存并等待完成。
2. 导出当前 Excalidraw viewport 为 PNG data URL，同时读取 viewport rect 和可见元素 ID。
3. 将截图作为 `referenceImages`，将视口坐标、可见元素 ID 和画布文件路径写入提示词。
4. 以 `permissionMode: "bypassPermissions"` 提交程序化 ACP 请求，但不传入 Canvas MCP server。

提示词结构保持精简：

1. 说明当前截图、视口坐标和可见元素 ID 是用户眼前内容的上下文。
2. 根据画布内容推断一个合理的下一步；无法确定时请求澄清。
3. 明确禁止调用任何 MCP；只能读取并直接修改指定 `.excalidraw` 文件。
4. 每次写入前重新读取目标文件，保持既有元素和文件结构不变。
5. 使用视口坐标和可见元素 ID 计算邻近落位；优先右侧、其次下方，避免重叠。
6. 保持 JSON 可解析、元素 ID 唯一，并只修改目标画布文件。
7. 不创建状态卡、占位元素或替代性前端产物。

前端不会对该模式返回的 artifacts 调用 `applyGenerationArtifactsToCanvasElements`，因此不会产生脱离 Agent 判断的固定落位。

AI 完成文件写入后，现有 Canvas Bridge 文件监听器等待文件稳定且 JSON 可解析，再向当前画布发送 `canvas.reload`。浏览器从服务端重新读取并合并场景，无需 MCP 执行刷新。

## 有界会话

会话 key 由项目 ID 和画布文件路径组成，存于本地浏览器存储。会话记录包含稳定的 ACP `threadId`/`conversationId`、供应商、创建时间和已接受请求数。

- 绝对有效期：30 分钟，从首次建立开始计算；活动中的连续请求不会续期。
- 最大轮数：8 次已接受请求。
- 供应商变化、超时或到达轮数上限时，下一次点击新建会话。
- 仅在 ACP 发出 `run.accepted` 后计入一次轮数，避免配置失败或连接失败消耗额度。

## 交互状态

底部 AI 按钮空闲时可点击；运行期间显示执行状态并提供取消。取消或失败不会在画布留下状态元素。成功后按钮恢复可用；若 Agent 返回澄清问题，前端以瞬时消息显示。

## 测试

- 会话 resolver：新建、复用、供应商变化、30 分钟绝对到期、8 次上限、仅 accepted 计数。
- 提示词 builder：包含截图、视口元数据、直接文件写入和邻近落位约束，不含 MCP、占位或视觉助手角色指令。
- 直连线程：显式 thread/conversation ID 复用，run ID 仍唯一，截图转发到 AI run 请求。
- 请求路由：视口模式显式使用 `bypassPermissions`，不传 Canvas MCP server；其他画布生成入口保持现状。
- 画布准备：AI 请求在服务端保存完成后才开始，截图结果包含 viewport rect 和可见元素 ID。
- 画布工具：视口模式不创建状态卡，也不做客户端 artifact 插入；外部文件写入由 Canvas Bridge 热重载。

## 非目标

- 不实现多任务并发、跨画布共享会话或服务器端会话持久化。
- 不改变现有带输入框、带场景设置的画布生成流程。
- 不引入客户端对生成内容尺寸或位置的预估。
- 不为侧边栏对话或其他 MCP 使用场景新增自动批准逻辑。

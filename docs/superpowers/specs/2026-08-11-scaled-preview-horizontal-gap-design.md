# 缩放预览水平间距设计

## 目标

在自定义尺寸和自适应桌面的缩放预览中，让视窗与左侧栏之间保留轻微但清晰的视觉间隔。缩放视窗左右各保留 8px，普通 100% 桌面预览继续铺满内容区。

## 方案

在 `ContentAreaView` 的预览容器测量中，为单视窗 `custom` 模式扣除 16px 水平空间，并在对应渲染容器上增加左右各 8px 的内边距。布局计算与实际盒模型使用相同的间距，避免视窗在窄窗口中横向溢出。

不改变手机、平板、分屏或多页面预览的布局参数，也不改变缩放算法、iframe 尺寸和侧边栏宽度。

## 测试与验收

- 源码回归测试确认 `custom` 缩放视窗使用左右 8px 的水平内边距。
- 布局单元测试确认 1000px 容器中的自定义缩放视窗最多使用 984px。
- 普通桌面预览仍为 `width: 100%`、`height: 100%`，不增加间距。
- 运行相关 Vitest，并在可用时通过本地管理页面检查缩放视窗与侧边栏的间距。

# 新建画布节点的项目作用域链接

## 目标

仅修复今后从资源选择器新建的画布嵌入节点：其打开链接必须包含当前 `projectId`。不迁移、不改写、也不在点击时修复已有画布节点。

## 根因

资源选择器在构造 `openUrl` 时调用深链生成器，但没有传入当前项目 ID；深链生成器仅在调用方明确传入时才输出 `projectId` 参数。

## 方案

将当前 `projectId` 传入资源选择器生成的文档、主题和原型深链。`createEmbeddableFromDrop` 继续保存该链接，不新增旧节点兼容逻辑。

## 验收

- 新建文档、主题、原型节点的 `customData.openUrl` 均带有当前 `projectId`。
- 预览链接的现有项目作用域行为不变。
- 不修改现有 `.excalidraw` 文件，也不改变点击旧节点时的解析逻辑。

# Make Voice Style Isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the Make voice entry fully styled without importing ACP's global stylesheet or overriding Make's root color tokens.

**Architecture:** Remove the ACP application-wide stylesheet import from the Make voice wrapper. Extend Make's existing Tailwind source scan to the ACP voice modules so their utility classes are generated against Make's own theme tokens.

**Tech Stack:** React 18.2.0, TypeScript 5.x, Tailwind CSS 4, Vitest, Vite.

## Global Constraints

- Use pnpm for repository development and verification.
- Do not modify the external ACP package or add compatibility shims.
- Preserve unrelated user changes in the dirty worktree.
- Do not commit unless the user explicitly requests it.

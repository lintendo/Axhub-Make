# 让 AI Agent 帮你启动 Axhub Make

这份文档给 AI Agent 使用。目标是启动 Axhub Make 管理服务，并为用户创建一个以后可以一键启动的桌面脚本。

## 目标命令

```bash
npx -y @axhub/make@latest
```

## 执行要求

1. 先检查当前环境是否可以直接执行目标命令。
2. 如果命令失败，不要停在报错处。请判断原因并处理，直到目标命令可以直接执行。
3. 启动成功后，确认管理页面已经打开；如果没有自动打开，请把终端里的访问地址复制给用户。
4. 在用户桌面创建一个启动脚本，用来以后直接启动 Axhub Make。
5. 创建脚本后，实际运行一次脚本，确认脚本可以正确启动 Axhub Make。
6. 最后告诉用户 Axhub Make 的访问地址、桌面脚本的完整路径，以及后续应该双击哪个脚本。

## 环境检查

请检查：

- Node.js 是否可用；
- npm 是否可用；
- npx 是否可用；
- 当前终端是否可以访问 npm registry；
- 当前系统是 macOS、Windows 还是 Linux。

如果缺少 Node.js、npm 或 npx，请按当前操作系统安装或引导用户安装。

如果是网络、权限、缓存、PATH、Node 版本或 npm 配置问题，请修复或给出可执行命令。每次修复后都要重新运行目标命令验证。

## 桌面启动脚本

脚本直接执行：

```bash
npx -y @axhub/make@latest
```

按系统创建对应脚本：

- macOS / Linux：创建可双击或可执行的 `.command` 或 `.sh` 脚本；
- Windows：创建 `.bat` 或 `.cmd` 脚本。

脚本里不要假设用户安装了 pnpm 或 Git。面向普通用户的启动流程优先使用 npm / npx。

## 完成后回复用户

完成后，请用简短文字告诉用户：

- Axhub Make 的访问地址；
- 桌面脚本的完整路径；
- 后续手动启动时应该双击哪个脚本；
- 如果还有未解决的环境问题，请明确说明原因和下一步操作。

# 默认资源推荐

按需查阅以下文档（不要一次性全部加载）：

- `references/default-chart-libraries.md` — 数据可视化图表库推荐（ECharts、Recharts 等），适用于仪表盘和数据展示场景
- `references/default-icon-libraries.md` — 图标库推荐（Phosphor、Radix 等），含风格选择指南
- `references/default-font-combinations.md` — 字体搭配方案，含标题/正文配对和中英文混排建议
- `references/default-animation-libraries.md` — 动画与过渡库推荐（Framer Motion、GSAP 等），按交互复杂度分级
